🔄 Synchronizacja cennika

Po podaniu publicznego adresu HTTPS do pliku JSON aplikacja sprawdzi aktualizacje przy otwarciu i co 24 godziny podczas użytkowania. Bez opublikowanego źródła cen nie ma automatycznej aktualizacji.

Brak skonfigurowanego źródła cen.

Twoje ceny wpisane ręcznie mają pierwszeństwo przed cennikiem online. Ceny niepotwierdzone nadal są szacunkowe; program nie pobiera cen automatycznie bezpośrednio ze stron sklepów.

Co aplikacja może, a czego nie

FORMA proponuje progresję podczas korzystania z aplikacji. Nie wysyła obecnie powiadomień, gdy jest zamknięta, nie śledzi kroków/GPS i nie synchronizuje automatycznie danych między urządzeniami. Ból lub kontuzja wymagają oceny człowieka, nie algorytmu.
